# 完賽鎖定與結果版本

## 鎖定時機

第三輪結算時，賽事會在同一個 Firestore transaction 中設為 `finished`、啟用 `resultLocked`、建立目前 run 的 `v1`，並遞增 tournament revision。一般自動同步不得再變更已鎖定的選手、配對、比分與賽制。

舊版已完賽資料第一次由管理員開啟時，系統會以 idempotent transaction 建立初始版本，不變更既有結果。

## 更正與回復

- 更正工作區只允許改比分與選手姓名，原始配對永遠保留。
- 可一次整理多筆修改；草稿不會發布至公開前台。
- 提交前必須填寫原因並預覽差異，第一次點擊只啟動 10 秒確認期，第二次才建立新版本。
- 回復舊版本不刪除較新的歷程，而是把舊快照複製成下一個版本，並保存來源版本及回復原因。
- 每個版本保存完整 Firestore-safe 賽事快照、差異、操作者與時間；版本文件禁止更新。

## 清除與場次 run

每次「清除內容」都建立新的 `runId` 並增加 `runNumber`。過去 run 的版本永久保留供查看，但只有目前 run 的版本可以回復；整場賽事永久刪除時才一併刪除所有版本。

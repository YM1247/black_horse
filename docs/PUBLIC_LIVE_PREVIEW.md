# 公開頁面分階段本機預覽（2026-11-16）

開發伺服器網址使用 `?event=DEMO&preview=round2`。頁面提供 registration、round1、round2、round3、finished、playoff、final 七個階段連結。

資料由 `src/publicPreview.js` 呼叫既有瑞士配對、比分、決賽資格及淘汰賽計算產生，包含虛構打師名、長名稱、已完成與等待比分的對戰。積分賽採 16 人三評審；最終戰依既有 24 人五評審規則進入八強。不同階段為獨立展示資料，不會寫入 Firebase。

公開頁僅在 Vite DEV 模式接受 preview 參數，預覽時跳過雲端訂閱；正式建置不載入測試資料模組。Live 注入僅供本機，結束時需以 live-server stop 移除，不可部署注入內容。

## 單場賽況／排名分頁

單場底部導覽改為 `view=matches` 與 `view=ranking` 兩個可分享的頁面網址，每次只顯示一頁。沒有指定 view 時，報名／進行中開賽況，完賽開排名；只有有排名資料時才提供排名頁。指定 view 優先於狀態預設，重新整理與瀏覽器上一頁會還原頁面，查詢不同賽事則重設選擇。相同賽事的切換保留測試參數、搜尋選手及輪次；淘汰籤表歸於賽況頁。系列頁仍使用原有場次／排名導覽。

驗證涵蓋完賽／進行中的預設、指定網址、切換顯示互斥、返回頁面、選手保留與無賽程導覽。公開單場與系列相關測試及正式建置通過；瀏覽器確認完賽初始僅見排名、切換後僅見對戰。

## 返回與搜尋流程（2026-11-16）

已載入單場時移除代碼切換欄，系列場次於標頭左上提供返回所屬系列首頁的連結；獨立場次沒有返回入口。原本底部系列入口整合至此，底部只切換賽況／排名。初始查詢入口仍可用代碼找賽事。

打師名搜尋改為不過濾的即時高亮，保留全部對戰及分組。符合者使用低對比灰藍底與細框，Enter／手機搜尋送出會捲到目前輪次或淘汰賽的首個符合對戰並移入鍵盤焦點。中文輸入組字期間不觸發送出；無結果時提供提示。此流程取代原本搜尋選手後產生個人對戰卡的方式，切換輪次與排名頁保留查詢文字。

賽事階段、更新／離線／快取狀態與時間統一放在標頭，內容區不再重複顯示更新列；離線警示與可用的重試仍保留。

驗證：完整應用測試、正式建置；瀏覽器實際輸入青焰並按 Enter，確認完整賽程保留、對戰高亮、捲動與焦點移轉。共享淘汰賽新增參數預設空字串，後台外觀不變。

搜尋提示精簡：有符合對戰時只保留高亮，不顯示數量或 Enter 提示；僅查無結果才顯示提示。建立淘汰賽後，淘汰籤表排在瑞士輪次賽程之前，導覽也以淘汰賽為首且預設選取；搜尋送出優先前往上方淘汰賽的符合場次。驗證搜尋成功／無結果提示、籤表文件順序及首個捲動目標，並確認正式建置與瀏覽器顯示。

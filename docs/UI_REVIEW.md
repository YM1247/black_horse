# 前後台逐頁介面檢查

## 檢查範圍與方式

2026-11-11，以實際 React 頁面搭配獨立測試資料進行瀏覽器檢查。管理後台以 1280×720、1920×1080 的 16:9 視窗為主；公開前台以 320×568、390×844、430×932 的手機直式視窗為主。

本輪包含 50 組後台頁面與尺寸，以及 57 組公開頁面與尺寸。另實際操作表單、確認視窗、鍵盤焦點、封存入口和頁內導覽。資料使用本機模擬內容，測試過程沒有發布正式站或更動正式賽事成績。

## 管理後台

| 頁面或狀態 | 檢查與修正 |
| --- | --- |
| 登入、驗證中、設定未完成 | 檢查錯誤 token 提示、表單標籤、等待狀態；設定未完成時停用登入按鈕。 |
| 管理首頁、無賽事、封存列表 | 系列選擇與新建賽事並排；後方的賽事編輯器設為 inert，減少誤觸與鍵盤進入背景；建立表單補上標籤。 |
| 黑馬系列、空場次、模擬系列 | 場次與公開設定並排；保留各場管理、清除及封存系列查閱入口。 |
| 新制報名、空白與滿額名單 | 左側登錄選手、右側名單與開賽操作；維持三欄名單及移除按鈕對齊。 |
| 改名衝突與資格席位新增 | 實際開啟核對提醒及新增表單，檢查欄位、錯誤、取消和剩餘名單操作。 |
| 積分賽記分、完賽、離線 | 左側記分、右側排行榜；長名字換行，比分按鈕依列對齊；離線有提示且停用寫入。 |
| 最終戰資格尚未齊備與資格預覽 | 三個外部資格席位並排；24 人預覽改為多欄，開賽操作移至預覽上方。 |
| 最終戰首輪、後續輪次、八強種子裁定 | 檢查種子說明、輪次切換、配對與排名閱讀順序。 |
| 八強、冠季軍完成、最終排名 | 淘汰賽記分優先呈現，瑞士制原始成績可展開查閱。 |
| 新制比分更正與取消 | 更正區取得焦點並顯示受影響輪次；取消後回到記分畫面。 |
| 舊賽制報名 | 修正長名字壓縮操作欄造成「改名」直排，保留獨立操作欄；擴大桌面可用寬度。 |
| 舊賽制列表及樹狀記分 | 修正長名字與勝率資訊把右側操作推到畫面外的問題；排行榜設為可捲動側欄。 |
| 舊賽制完賽與結果更正 | 姓名及各輪可展開；桌面左側編輯、右側顯示原因、送出、排名預覽及版本。送出期間鎖定姓名、比分、原因及版本操作。 |
| 改名、棄賽、清除與永久刪除提示 | 實際開啟及取消；Tab 焦點保持在視窗內，Escape 可取消。檢查長標題換行與視窗高度；未執行刪除或清除。 |
| 版本回復 | 實際選取舊版本並取消回復；檢查原因標籤及二次確認提示。 |

## 公開前台

| 頁面或狀態 | 檢查與修正 |
| --- | --- |
| 單場與系列查詢入口 | 輸入欄位及查詢按鈕在三種手機寬度內完整顯示。 |
| 載入、查無資料、權限錯誤、設定未完成 | 保留查詢和返回入口，載入狀態具有狀態回報。 |
| 報名中、尚無賽程或排名 | 顯示沒有賽程、沒有排名的提示。 |
| 瑞士制進行中、完賽排行榜 | 先後攻、比分、戰績、積分與長打師名均可直向閱讀；上方導覽可直達各輪及排名。 |
| 最終戰八強、冠季軍結果 | 檢查種子序、先後攻、比分與獎牌名次，保留八強和瑞士排名的導覽。 |
| 系列空白與完整排行榜 | 場次卡縮減內距；每位選手的四場得分、採計標示及總積分可直向閱讀。 |
| 離線快取 | 提示快取狀態及更新時間，重試操作至少 44px 高。 |
| 所有返回與跳轉連結 | 擴大手機點擊範圍；逐一點擊確認目標不被置頂導覽遮住，瀏覽器頁內歷史不會清掉已載入比分。 |

## 驗證結果與範圍限制

- 上述 107 組頁面與視窗尺寸沒有頁面層級的水平溢位。
- 93 項既有與導覽回歸測試通過；補上送出中禁止修改更正草稿的測試後，共 94 項應用測試通過。
- 正式版建置成功。既有共用 JavaScript 約 997kB，建置仍有超過 500kB 的提示。
- 本輪以桌面瀏覽器的視窗尺寸模擬手機，尚未在實體 iPhone、Android 或 Safari 完成實機驗收。

# 賽事生命週期

## 清除、封存與永久刪除

- 清除內容：只適用系列場次。保留場次卡、名稱、代碼、公開狀態、audit 與所有舊 run 版本；建立新的 run 並清空名單、輪次與比分。
- 封存：只適用獨立單場。資料完全保留，但預設不出現在獨立賽事列表；勾選「顯示已封存賽事」即可取消封存。
- 永久刪除：賽事文件、`auditLogs` 及 `versions` 都會移除，無法復原。系列場次另會從公開投影及系列卡片移除，系列層保留不含賽事內容的刪除稽核。

## 可續跑刪除流程

系列場次永久刪除依序執行：

1. 立即重建公開系列投影，排除目標場次。
2. 將賽事設為未公開並寫入 `deletionStatus="deleting"` 及開始刪除 audit。
3. 分批刪除 `tournaments/{eventCode}/auditLogs`。
4. 分批刪除 `tournaments/{eventCode}/versions`。
5. 刪除賽事主文件。
6. 最後從 `series/{seriesId}.events` 移除場次卡，並在 `series/{seriesId}/deletionAudits` 建立不可修改的刪除紀錄。

獨立賽事採相同的標記與分批刪除，但沒有系列卡片步驟。每一步都可重複執行；中途斷線或發生權限／版本衝突時，畫面顯示「刪除未完成」。管理員重新按下永久刪除後會略過已不存在的資料，從剩餘步驟續跑。

系列刪除 audit 只保存場次代碼、顯示名稱及當時是否仍有賽事文件，不保存已刪賽事的選手、比分或版本內容。

## 公開狀態

標記刪除中的賽事即使先前為公開，也不會被放入新的公開系列投影。單場文件在刪除前同步設為 `isPublic=false`，避免觀眾在子集合清理期間繼續讀取。

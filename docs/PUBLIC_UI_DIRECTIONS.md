# 公開頁面主視覺與 UX 方案｜2026-11-15

## 已確認需求

使用今年黑馬書法 Logo 與黑紅藍海報延伸公開頁面，先提出選擇，不改後台。使用者確認比賽當天手機查詢自己的對戰、比分與排名為首要任務，並選擇先確認完整效果圖再實作。現有公開頁面的功能與資料規則保持為產品依據。

## 現況與共同改善

檢視 `PublicTournamentPage.jsx`、`PublicSeriesPage.jsx`、CSS、近期手機驗收畫面及目前本機查詢入口。現有入口先要求輸入代碼；單場進行中先顯示完整瑞士制樹狀圖，查個人對戰需沿整張圖尋找。系列場次與排名已有手機版，但缺少今年主視覺。

候選方案共用：選手搜尋、當前輪次優先、明顯先後攻與比分、可切換完整賽程與排名、手機容易觸及的導覽。完整樹狀圖仍保留。即時與離線狀態以文字標示，不只靠顏色。新入口預設場次及個人關注是否跨次保留，仍待正式實作前確認。

所有效果圖均為概念示意；示例選手、對戰及比分不是正式賽事資料。海報日期可用於活動資訊，不據此推定真實賽事狀態。

## 視覺推導

文化場景：校園 Wotagei／打師賽事，選手與觀眾在場邊拿手機查賽況。典型儀表板與純宣傳長海報都無法獨自滿足本次目標。

候選系統依相關性排序：

1. 現場演出墨刷海報：黑紅品牌前導，白字與明亮藍色承載查詢。
2. 轉播比分畫面：平整大比分，輪次與先後攻固定對位。
3. 手寫對戰簽表：白底黑字、紅色圈選的個人路徑。
4. 活動入場票：一場對戰為一張票根，狀態與輪次形成順序。
5. 場館指示牌：編號輪次、大箭頭與遠距辨識。
6. 賽事場刊：系列目錄、場次索引與積分表。
7. 場邊記分板：緊湊品牌抬頭、紅色輪次帶、對戰列與排名分頁。

Impeccable 方向探索種子 `6849939d`，初輪主提案為第 7 項；第 1 項為設計推薦。使用者後續選擇 A 的介面結構與 B 的品牌主視覺，並要求整體更柔和。

## 三個主要方案

- A 場邊戰報：黑紅、規整對戰列與大比分；先查賽、再展開細節。品牌克制，查詢效率最高。
- B 墨勢主場：墨馬與紅色筆觸集中在頁首，下方為清晰賽況；品牌最強，需限制手機頁首高度。推薦。
- C 賽程通行證：白底、深藍、朱紅，個人對戰以票券呈現，各輪依序保留；戶外易讀，與黑底海報的距離較大。

## 外部形式比較

判斷依據僅為「選手／觀眾認同」及「查賽清晰度」。原有品牌約束優先於參考形式。

| 參考形式 | 結論 | 對主提案的要求 |
| --- | --- | --- |
| 定向越野地圖 | 不列主選：地形符號與本賽事無關，手機全圖不利找單場 | 保留當前輪次與完整賽程的上下文 |
| 溫暖消費 App | 不列主選：品牌辨識較弱，逐卡的資訊密度不利同輪比較 | 觸控區舒適、文案直白、常用導覽可用拇指觸及 |
| 航空票券夾 | 保留為 C：個人逐輪路徑清楚，品牌連結較弱 | 深藍紅白與票根欄位轉譯為先後攻、比分、輪次；不加入登機等隱喻文案 |
| 午夜交通路線圖 | 不列主選：路網不是實際場館地圖，容易混淆配對與晉級 | 手機聚焦當前輪次，保留相鄰輪次入口 |
| 透明頁片手冊 | 不列主選：紙層與色彩分頁不符合現場查比分的直覺 | 分頁切換時維持搜尋與當前狀態 |
| 翻牌出發看板 | 不列主選：中文字長度與動態翻牌干擾選手掃讀 | 每列比分、選手和狀態欄位對齊；更新不造成版面跳動 |

## 交付與範圍

效果圖與提示詞位於 `.impeccable/mocks/decision/`；互動方案選擇頁只收集方向。概念階段不更動正式頁面、Firebase 資料或部署。桌面規劃為左側當前輪次、右側個人查詢／即時排名，沿用選定手機方案的視覺語言；完整桌面稿留待方向選定。

- 絕對黑調整為柔和炭灰；白字改為暖白，輔助資訊改為灰藍。
- 大面積鮮紅帶、粗紅分隔、紅色導覽底移除；低飽和紅只保留在當前輪次與導覽狀態。
- 保留 B 的墨馬與書法，移除大部分噴濺及斜向刷痕，頁首控制在短版比例。
- 降低標題與比分以外文字的視覺重量，留白與細分隔取代重色框線。
- 效果圖以內建 ImageGen 參照 A、B 編修，保存原稿與提示詞；示例成績及圖中文字均不作正式資料或最終排字。

本輪只修訂效果圖，尚未開始應用程式實作；修訂強度待使用者確認。

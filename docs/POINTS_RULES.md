# 積分賽名次積分規則

## 適用範圍

- 單場賽事最多 32 位選手。
- 參賽人數不足 32 人時不重新分配或等比例換算，仍直接依實際最終名次套用固定級距。
- 第 33 名以後不在賽制範圍內，系統會在報名階段限制名單最多 32 人。

## 現行計算行為

- 積分使用排名規則產生的 `displayRank` 計算。
- 自動排名條件完全相同的並列選手取得相同名次與相同積分，並維持「需加賽」提示。
- 棄賽選手不列入有效排名，單場積分為 0。
- 進行中賽事不顯示本場積分；賽事完成後，管理後台與公開頁才顯示最終積分。
- 目前只計算並顯示單場積分；跨四場累積、結果鎖定與更正後重算會在 Phase 3 後續功能實作。

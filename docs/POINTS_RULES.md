# 積分賽名次積分規則

## 黑馬記念26-27 積分賽

每站上限 48 位。先排除主辦方選手，再依戰績分組，按組內共同名次給分。棄賽為零分。

| 戰績 | 組內由高至低 |
| --- | --- |
| 3–0 | 100、95、90、85、75、70 |
| 2–1 | 55、47、40 |
| 1–2 | 30、24、18 |
| 0–2 或 0–3 | 10 |

三段分界為第 `ceil(n/3)` 與第 `ceil(2n/3)` 名。10 人分為 4／3／3，4 人分為 2／1／1，並列者依共同名次取得相同分數。四站取最佳三站，決賽不計系列分。

## 舊版名次積分適用範圍

- 單場賽事最多 32 位選手。
- 參賽人數不足 32 人時不重新分配或等比例換算，仍直接依實際最終名次套用固定級距。
- 第 33 名以後不在賽制範圍內，系統會在報名階段限制名單最多 32 人。

## 舊版計算行為

- 積分使用排名規則產生的 `displayRank` 計算。
- 自動排名條件完全相同的並列選手取得相同名次與相同積分，並維持「需加賽」提示。
- 棄賽選手不列入有效排名，單場積分為 0。
- 進行中賽事不顯示本場積分；賽事完成後，管理後台與公開頁才顯示最終積分。
- 模擬賽系列會將三場已完賽賽事的單場積分累加；未參加、進行中與棄賽場次均計 0 分。

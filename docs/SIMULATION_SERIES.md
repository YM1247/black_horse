# 模擬賽系列賽

## 初始設定

模擬賽初次使用時提供三場預設場次，均採三位評審與兩敗淘汰：

| 場次名稱 | 賽事代碼 | 評審 | 淘汰規則 |
| --- | --- | ---: | --- |
| 8/19 | `MOCK819` | 3 位 | 累積兩敗後淘汰 |
| 8/21 | `MOCK821` | 3 位 | 累積兩敗後淘汰 |
| 8/26 | `MOCK826` | 3 位 | 累積兩敗後淘汰 |

每場都是獨立的 Firestore 賽事文件，各自保存報名名單、輪次、比分與公開狀態。選手可只參加其中一場或數場，某一場的名單不會複製到其他場次。

系列場次清單會保存於 `series/simulation-series`。在尚未建立此文件前使用上表作為初始值；第一次新增或刪除場次後，後台改以雲端設定為準，因此被刪除的初始場次不會自行恢復。

## 後台操作

1. 進入 `?admin=1` 並以管理 token 登入。
2. 在雲端管理首頁選擇「模擬賽」。
3. 尚未建立的場次會顯示「建立」；建立時直接使用固定賽制並預設公開。
4. 已建立的場次會顯示「管理」，進入後沿用一般雲端賽事的報名、配對、比分與公開網址功能。
5. 從場次返回時會回到模擬賽頁，可繼續管理其他場次或查看累積排名。

## 新增、清除與刪除

- 新增場次：輸入場次名稱及 4–10 位英數賽事代碼，建立保留名稱與賽制標籤的場次卡；再按卡片上的「建立」產生空白雲端賽事。
- 清除內容：只在已建立的賽事顯示。保留場次名稱、代碼、三位評審／兩敗淘汰標籤、公開狀態與操作紀錄；清除所有選手、輪次、比分與結果，並回到報名階段。
- 刪除場次：刪除整張場次卡。若雲端賽事已建立，也會一併刪除賽事文件及其所有操作紀錄；這項操作無法復原。
- 新增代碼不可與其他系列場次或既有獨立賽事重複；刪除完成後該代碼才可再次使用。

建立的賽事文件另外保存 `seriesId` 與 `seriesEventId`，供後續資料查詢及系列功能擴充；場次仍以賽事代碼連結對應的賽事文件，以相容已經建立的資料。

## 系列積分

- 單場必須進入「已完賽」狀態，該場名次積分才會加入系列總分。
- 名次積分使用既有 32 人制固定級距；人數不足 32 人仍依實際名次計算。
- 跨場選手以去除前後空白後的完整名稱精確合併，大小寫或其他字元不同會視為不同選手。
- 未參加、尚未完賽、棄賽或無有效名次的場次均為 0 分。
- 總積分相同時顯示相同系列名次，並依選手名稱穩定排序。

系列排名由後台已訂閱的所有系列場次即時資料計算，不另寫入一份可能過期的排行榜文件；場次更正並完成同步後，排名會隨資料重新計算。

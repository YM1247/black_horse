## 核准方向與範圍

2026-11-15 使用者核准 A 的查賽結構、B 的品牌識別及最後一版柔和水墨修訂，並明確要求實作、部署。更新公開查詢入口、單場賽況、系列場次與系列積分。後台樣式、Firebase 資料格式、權限和賽制計算維持原狀。

主視覺使用提供的完整馬頭、圓弧與書法合圖。`public/brand/black-horse-original.png` 與原始附件逐位元一致，SHA-256 為 `be2256985b298c34e361b1244f966d59371904add6afb84e8f3c379dae250aa8`。使用 CSS 改顏色及混合白底，圖片等比例顯示，顯示窗只避開空白邊緣，沒有重繪、拆分重排或裁掉筆觸。頁首不另印「26–27」。系列識別代碼與原始賽事資料保留。

水墨背景由獨立素材 `public/brand/ink-wash.webp` 提供，約 28KB，保留暗紅暈染與乾刷筆觸；背景不含 Logo 或品牌文字。生成提示詞記錄於旁邊的 JSON。原圖來源則使用獨立 JSON 記錄，避免更動原圖檔案本身。

## 公開操作

- 首頁維持賽事代碼查詢，提供黑馬系列入口。既有 `?event=代碼`、`?series=代碼`、公開 QR Code 與歷史連結繼續使用。
- 單場預設顯示最新一輪；手動選輪後保留選定輪次。搜尋只比對公開打師名，選擇一位選手後顯示其對戰、實際先後攻、比分及狀態。
- 選手選擇只存在目前頁面，不儲存本名、電話或跨裝置個人關注，也不要求登入。
- 存在淘汰賽時，個人卡優先顯示該選手目前最新的淘汰對戰；手動切換瑞士輪次可查原輪次。合作賽冠軍戰區分「局數」與各局「票數」，BO3 只完成一局不會標為完賽。
- 沒有對戰的種子、尚未開賽、找不到選手、載入、找不到賽事與離線快取均提供對應提示。
- 手機底部導覽可快速前往賽況、排名與系列；桌面將對戰與排名並排。完整瑞士樹狀圖、八強／十六強籤表、冠亞季軍和原有排名數據持續提供。
- 系列排行榜可用打師名篩選，保留原名次及原得分。最佳三站計分及同分規則沒有變更。
- 切換賽事／系列代碼收於可展開區塊，避免在正常查賽流程占用過多空間。

## 實作邊界

`PublicLayout.jsx` 提供原圖品牌、搜尋欄與導覽，`PublicEventLive.jsx` 處理選手／輪次選擇與唯讀對戰。`public.css` 所有視覺規則限定於公開根節點；共享瑞士樹狀圖的 `publicView` 只在公開頁啟用，後台維持原配色及記分控制。

即時資料仍由既有 Firestore listener 接收。沒有新增私人選手查詢、寫入、快取或計分來源。原圖約 1.4MB 因使用者禁止更改而完整保留；背景以 WebP 壓縮。既有共用程式超過 500KB 的建置提示仍存在，本次不涉及拆分後台程式。

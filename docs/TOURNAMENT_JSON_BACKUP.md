# 單場賽事 JSON 備份

賽事後台底部的「賽事資料工具」可下載目前已載入的賽況。檔名含賽事代碼與 UTC 匯出時間。建議在抽籤後、各輪記分完成及完賽時各留一份。離線但後台仍開著時也能下載，未送出的表單輸入不在檔案內。

同一工具內展開「從備份還原」，選擇原始 JSON、核對場次與輪數，再輸入本場代碼。還原需連線。若選檔後賽況改變，必須重新核對。

檔案保存本場選手、輪次、對戰、比分、賽制及適用的晉級與淘汰賽資料。格式版本與 SHA-256 檢查用來辨識格式及偵測意外修改。還原沿用現行賽事身分、公開設定、執行批次及版本序列，透過同一交易寫入賽況、摘要、新版本與操作紀錄。私人選手通訊錄、其他場次、系列設定與雲端操作歷史不在單場檔案內。

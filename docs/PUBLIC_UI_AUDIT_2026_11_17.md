# 公開介面驗收與修正（2026-11-17）

## 範圍與結論

延續已核准的柔和水墨主視覺，檢查公開查詢、系列首頁、瑞士賽況、淘汰賽及排名。後台視覺不重新設計，賽制與正式資料不變。未發現阻擋上述主要查詢流程的問題；以下實際發現的瑕疵已修正。

## 修正

- Logo 黑底方塊：背景搬到 html 畫布後，main 的 isolation 讓 screen 混色無法使用水墨背景。移除已不需要的隔離層，保持原始圖檔、展示視窗、比例及暖白改色，讓原圖白底轉成的黑色正確融入背景。
- 排名逐列分隔：原本只取消 border-bottom，但舊版共用 CSS 設定的是 border-top。公開排名列改為 border: 0，保留標題、分組與輪次選單的線。
- 鍵盤焦點：提高公開焦點規則的局部優先度，避免舊版橘色規則覆蓋酒紅；搜尋輸入不再和外層 focus-within 重複畫框。
- 連網快取提示：將「正在連線，暫時顯示快取資料」與真正離線分開，保留實際同步狀態。
- 讀取失敗：單場及系列頁可在連網時重試訂閱；離線時不顯示無法執行的重試。
- 系列場次不存在或取消公開：以已完成訂閱的 null 與仍等待訂閱區分，顯示「尚未公開」，不會永久顯示載入中。
- 系列手機積分格：最後一格是否跨兩欄與桌面無結果列的 colspan，統一依實際計分場次計算，不將最終戰算入。
